# 💎 Tip Calculator

A responsive tip calculator built using HTML5, CSS3, and JavaScript.

## Features

- Enter the bill amount.
- Select a tip percentage: 5%, 10%, 15%, or 20%.
- Enter a custom tip percentage.
- Specify the number of people sharing the bill.
- Calculate the tip amount and total bill.
- Display the amount each person should pay.
- Validate bill amount, tip percentage, and number of people.
- Update results automatically when inputs change.
- Reset the calculator.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Calculator structure
- `style.css` — Styling and responsive layout
- `script.js` — Calculation and validation logic

## Formula

- Tip Amount = Bill Amount × Tip Percentage / 100
- Total Bill = Bill Amount + Tip Amount
- Per Person = Total Bill / Number of People
